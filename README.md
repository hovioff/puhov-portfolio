# Портфолио работ

Минимальный мобильный каталог работ: блоки проектов, отдельная страница каждого кейса и локальная админка.

Запуск из этой папки: `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

- `index.html` — только каталог работ и фильтры.
- `project.html?id=meatbone` — отдельный адрес страницы проекта.
- `admin.html` — добавление и редактирование проектов, дат, сроков и слайдов.
- `styles.css` — общий дизайн.
- `js/` — каталог, данные и поведение страниц.
- `assets/meatbone/` — пять слайдов из исходного файла.

Админка сохраняет данные в IndexedDB этого браузера; слайды уменьшаются перед сохранением. Для общей публикации на сайте потребуется серверное хранилище.
